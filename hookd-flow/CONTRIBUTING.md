# Contributing to HOOKD Flow

Thanks for helping! This is a small open-source project.

1. Fork the repo and create a branch: `git checkout -b my-change`
2. Install and run: `npm install` then `npm run dev`
3. Keep business logic in `src/lib`, UI in `src/components` and `src/pages`.
4. Before opening a pull request, run `npm run build` (type-checks and builds). It must pass.
5. Describe what changed and how you tested it.

Guidelines: no new dependencies without a good reason, no real client data or secrets in code or screenshots, and never add features that collect passwords or credentials.
